# Browser verification

Use the standalone `sbx` Linux microVM strategy from Swimfrancisco. The
launcher copies Git history, tracked edits, and non-ignored new files.
It mounts no host directories, forwards no application credentials, and
provides a private desktop through a loopback noVNC port.

Create with `just sandbox helixium codex`; run commands with
`just sandbox-exec helixium devenv shell -- just check`. Keep a foreground
sbx session connected while using the desktop. Discover ports with
`sbx ports helixium` after each restart. Use `just sandbox-export helixium`
before removal; `just sandbox-remove helixium` also exports first.

`dist/chrome`, `dist/firefox`, and `dist/safari` are generated by `npm run
build`. Browser tests must record installed-extension results separately
from script-only engine smoke tests. Linux WebKit is not Safari. Safari
requires an isolated macOS VM and an enabled Safari Web Extension.

Validation is still in progress. No completed browser matrix is claimed.
